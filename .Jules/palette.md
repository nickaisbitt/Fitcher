## 2026-05-05 - Empty States and Focus Rings
**Learning:** Adding actionable empty states is significantly more engaging than just displaying "No data". Always give users a next step. Furthermore, ensuring icon buttons have `focus-visible` styles enhances keyboard navigation. In this application, a Babel compilation error occurs natively in `index.html` preventing immediate rendering verification with Playwright, requiring fallback to `read_file` or bypassing if the Babel issue is pre-existing.
**Action:** When working on UX for React components in single-file prototypes, replace simple string empty states with a composed UI involving an icon, helper text, and a CTA button mapping to other sections. Wait or intercept pre-existing script errors to allow Playwright rendering.
