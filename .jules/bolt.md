## 2024-05-18 - Avoid O(N²) array shift and heavy allocations in Hot Loops
**Learning:** Found a severe performance bottleneck in `calculateTradeStats` (which evaluates many trades, especially in grid strategies). The logic used `openBuys.shift()` inside a while loop, pushing complexity to O(N²). Additionally, object spreading (`{ ...trade, ... }`) created unnecessary GC overhead. Welford's algorithm also proved useful to eliminate intermediate array allocations when calculating rolling variances for Sharpe Ratio and dynamic slippage.
**Action:** Replace `Array.shift()` with pointer indexes in hot loops. Direct property assignment should be preferred over object spread syntax when creating many objects. Use Welford's online algorithm to compute variance and standard deviation in a single pass instead of chaining `.map` and `.reduce` array iterations.
