## 2024-05-06 - Replacing O(N²) array operations
**Learning:** Heavy use of `Array.shift()`, object spreading (`...obj`), and multiple `.reduce()` chained loops within `for` loops in Node.js creates significant GC thrashing and O(N²) complexity loops, forming a substantial bottleneck on performance paths like BacktestEngine execution.
**Action:** Replace `.shift()` with index pointers, `.splice()` for bulk deletion, and replace `.reduce()`/`.filter()` chaining with single pass loops.
## 2026-06-02 - Optimizing Array O(N) operations in hot paths
**Learning:** Multiple array operations using chained reduce/filter/map map inside loops in metricsCollector, strategyOptimizer, PaperTradingEngine and SmartOrderRouter are creating GC overhead and N-pass iterations instead of single pass loops. Calculating variance via 2-pass reduce creates a bottleneck, whereas Welford's online algorithm can compute mean and standard deviation in a single pass.
**Action:** Replaced chained array functions with single pass loops and optimized variance/stdDev calculation using 1-pass Welford's online algorithm. Also replaced Math.random().toString(36) in SignalAggregator with crypto.randomBytes(4).toString('hex').
