## 2026-05-18 - Improve Empty States & Accessibility
**Learning:** Empty states in trading interfaces like "No open position" often lack clear direction. Simple text strings can leave users confused about how to actually initiate an action. Adding icons (`📦`, `📉`) and clear subtext ("Execute trades to see exposure") significantly improves the perceived usability and guidance. Furthermore, simple HTML elements like `<input type="range">` are often overlooked for accessibility; adding `focus-visible:ring-2 focus-visible:ring-cyan-500` ensures keyboard users can track their interactions. `aria-expanded` is crucial for toggle buttons.
**Action:** Always consider the actionable next step when designing an empty state. Ensure all interactive form controls have `focus-visible` styles explicitly defined if default styles are removed or obscured. Check toggle controls for proper ARIA attributes like `aria-expanded`.
